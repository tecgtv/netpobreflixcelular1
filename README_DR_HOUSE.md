# Dr. House integrado

- Categoria: Drama.
- Série visível somente em Séries, não na Home.
- Temporadas e episódios ficam incorporados diretamente em `series_dr_house.js`.
- Player de séries reutilizado, incluindo painel interno de temporadas/episódios.
- Mais informações usa o mesmo componente inline do restante do catálogo.
- A interface mantém a temática escura inspirada em serviços de streaming.
- As imagens usadas no cadastro ficam referenciadas diretamente no código da série; não há arquivo M3U adicional.
